# AssemblyGrid documentation index

This documentation is organized around the separation between the benchmark definition, the canonical implementation, algorithm support, and reproducibility.

1. **GETTING_STARTED.md** — install, run, inspect a canonical episode.
2. **CANONICAL_INTERFACES.md** — what decentralized agents see/do and what is privileged.
3. **CONFIGURATION_AND_INSTANCES.md** — instance identity, profiles, seeds, official realizations.
4. **RECIPE_AUTHORING.md** — create and validate recipe DAGs.
5. **ALGORITHM_INTEGRATION.md** — integrate decentralized, CTDE, value-decomposition, graph, or optimization methods without changing the core.
6. **TROUBLESHOOTING.md** — common setup, wrapper, metric, and reproducibility issues.

The training code of the reported MARL campaign is documented in `reference_training/README.md`.

Normative theory remains in the authoritative manuscript. These files explain how to use the shipped v1 implementation without redefining it.
